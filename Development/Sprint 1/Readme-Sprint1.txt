LIST OF REQUIREMENTS COMPLETED IN SPRINT 1


Annex A - User Endpoint Device Compliance Check (Control 8.1): Evaluate compliance of user endpoint devices against security policies.

Dashboard Development: A user-friendly, role-based dashboard interface that allows navigation to various system features, including document upload, compliance checks, and report viewing. Improvement made in terms of accesiblity to streamline the process

Annex A - Privileged Access Rights Compliance Audit (Control 8.2): Review allocation and management of privileged access rights for compliance.

Annex A - Protection Against Malware Compliance (Control 8.7): Audit compliance measures against malware threats, ensuring policy adherence. Our software includes checking whether firewall is enabled and maintains a blacklist/whitelist to restrict access to vulnerable sites, it also checks if the device has neccesary anti-virus/ anti-malware softwares installed. 

System Notification Module: Notify users about audit results, compliance status, and actions for non-compliance.

Result Visualization Screens: Create additional screens in the dashboard to display detailed results for individual compliance controls.

Login/Logout Authentication: Secure user authentication and access control implemented, ensuring that only authorized users can access the system. Role-based access control is included to grant appropriate permissions.

Dashboard Development: A user-friendly, role-based dashboard interface that allows navigation to various system features, including document upload, compliance checks, and report viewing.

Document Uploader Module: A feature that lets users upload documents necessary for compliance checks, supporting file validation (PDF, DOCX) and ensuring secure storage.

AI Compliance Check Module:
Annex A - Control 6.2 (Terms and Conditions of Employment): The module evaluates uploaded employee contracts, analyzing key clauses to ensure they contain confidentiality agreements, non-disclosure clauses, and adherence to employment terms.

Annex A - Control 6.5 (Responsibilities After Termination or Change of Employment): The module checks for clauses covering responsibilities post-employment, including asset return, data handling, and confidentiality maintenance.

Annex A - Control 6.6 (Confidentiality or Non-Disclosure Agreements): This module ensures contracts include well-documented confidentiality agreements, mentions of regular review, and signature requirements.

Compliance Report Generation: The system compiles the results of compliance checks into a structured, detailed report that users can access through the dashboard. This report provides insights based on the evaluation of employee contracts for each control.
